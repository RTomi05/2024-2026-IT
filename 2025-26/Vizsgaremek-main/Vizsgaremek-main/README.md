# Feladat leírása
• Egy online naplózási szolgáltatás, ami átláthatóbbá teszi a költségvetéseidet vagy csoportodét, illetve alkalmas statisztikákra, árkövetésre, bróker árkövetésre és weboldalak kuponjainak mutatására.

• Probléma amire készül:
-> Sokan nem tudják felelősséggel és átláthatóan kezelni pénzüket, költségvetéseiket, mert nem látják át az egész képet és csak részletekben gondolkodnak.

# Felhasználói szerepkörök
User, KuponModerator

# A funkciók között szerepel:
• Regisztráció, bejelentkezés 
• Költségvetések kezelése (mentése, szerkesztése, törlése)
• Költségvetések alapján statisztika készítése (pl. egy hónapban mennyit költött és mire)
• Árucikkek átlagos árkövetése
• Bróker árfolyam követése
• Kuponok mutatása felhasználóknak

# Működési logika

User:
• Regisztrálás, bejelentkezés
• Felhasználói / Csoport beállítások
• Csoportok létrehozása / csatlakozás
• Saját költségvetések kezelése
• Árkövetések megtekintése
• Kuponok megtekintése

KuponModerator:
• Kuponok tesztelése, felrakása
